# Uso de los datos

**Actualización:** 15 de octubre de 2026.

## Qué cubre esta página

Esta página indica cómo se pueden usar los datos que sirve la API de DolarApi. El programa del proyecto tiene otra licencia.

## El programa y los datos

El código está bajo la [licencia MIT](https://github.com/enzonotario/esjs-dolar-api/blob/main/LICENSE). Esa licencia cubre el programa. No cubre las series.

## Uso permitido

Se puede consultar la API y usar las respuestas. Eso incluye conservar una copia local y publicar un trabajo basado en esos datos.

Una publicación que use estos datos tiene que citar el servicio.

## Cita

> DolarApi <https://dolarapi.com>

## Fuentes de terceros

Parte de las series proviene de terceros. Recomendamos citar también la fuente original. DolarApi no cambia la licencia de esa serie y no la reemplaza.

## Frecuencia

No hay un máximo numérico de consultas. Conviene conservar una copia local y no repetir la misma consulta en un bucle. Una consulta cada 3 horas y por serie es una medida adecuada.
